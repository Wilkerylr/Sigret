═══════════════════════════════════════════════════════════════
2. CAMBIAR EL ICONO ESTÁTICO (PASO A PASO)
═══════════════════════════════════════════════════════════════

PASO 1 — Elegir un icono
─────────────────────────
Visita https://lucide.dev/icons y elige el que más te guste.
Por ejemplo: "PanelRightClose", "PanelLeftClose", "X", "ChevronLeft".

PASO 2 — Abrir el archivo
─────────────────────────
Abre:  frontend/src/componentes/ui/sidebar.tsx

PASO 3 — Cambiar la importación (línea 5)
──────────────────────────────────────────
Busca esta línea:

  import { Menu } from "lucide-react"

Reemplázala con el icono que elegiste. Por ejemplo:

  import { PanelRightClose } from "lucide-react"

Si quieres importar MÁS de un icono, sepáralos con coma:

  import { PanelRightClose, PanelLeftClose } from "lucide-react"

PASO 4 — Cambiar el icono en el JSX (línea 276)
────────────────────────────────────────────────
Busca:

  <Menu />

Reemplázalo con:

  <PanelRightClose />

PASO 5 — Guardar el archivo
────────────────────────────
Guarda los cambios (Ctrl + S). El nuevo icono aparecerá
automáticamente al recargar la página.

3. CAMBIAR EL ICONO DINÁMICAMENTE (ABIERTO VS CERRADO)
═══════════════════════════════════════════════════════════════

Si quieres que el icono CAMBIE dependiendo de si el sidebar
está expandido o colapsado, sigue estos pasos:

PASO 1 — Importar ambos iconos (línea 5):

  import { PanelRightClose, PanelLeftClose } from "lucide-react"

PASO 2 — Obtener "state" del sidebar (línea 261):

  function SidebarTrigger({ ... }) {
    const { toggleSidebar } = useSidebar()
    const { state } = useSidebar()  // ← AGREGAR ESTA LÍNEA
    ...

PASO 3 — Usar el state para mostrar un icono u otro (línea 276):

  {state === "expanded" ? <PanelRightClose /> : <PanelLeftClose />}

  Esto mostrará:
  - "PanelRightClose" (←) cuando el sidebar ESTÁ expandido
  - "PanelLeftClose"  (→) cuando el sidebar ESTÁ colapsado

CÓDIGO COMPLETO DE LA FUNCIÓN DESPUÉS DEL CAMBIO:

┌────────────────────────────────────────────────────────────┐
│ function SidebarTrigger({                                  │
│   className,                                               │
│   onClick,                                                 │
│   ...props                                                 │
│ }: React.ComponentProps<typeof Button>) {                  │
│   const { toggleSidebar } = useSidebar()                   │
│   const { state } = useSidebar()                           │
│                                                            │
│   return (                                                  │
│     <Button                                                 │
│       data-sidebar="trigger"                                │
│       data-slot="sidebar-trigger"                          │
│       variant="ghost"                                       │
│       size="icon"                                           │
│       className={cn("size-7", className)}                   │
│       onClick={(event) => {                                 │
│         onClick?.(event)                                    │
│         toggleSidebar()                                     │
│       }}                                                    │
│       {...props}                                            │
│     >                                                       │
│       {state === "expanded"                                 │
│         ? <PanelRightClose />                               │
│         : <PanelLeftClose />                                │
│       }                                                     │
│       <span className="sr-only">Toggle Sidebar</span>       │
│     </Button>                                               │
│   )                                                         │
│ }                                                           │
└────────────────────────────────────────────────────────────┘

5. DÓNDE ENCONTRAR MÁS ICONOS
═══════════════════════════════════════════════════════════════

Catálogo oficial de lucide-react (todos los disponibles):
  https://lucide.dev/icons

La librería ya está instalada en el proyecto:
  frontend/node_modules/lucide-react

Para buscar un icono específico dentro del proyecto:
  npm list lucide-react --prefix frontend

Para instalar una versión más reciente (si hiciera falta):
  npm install lucide-react --prefix frontend
